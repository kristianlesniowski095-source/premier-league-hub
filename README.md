# Premier League Hub 

A Python-based Premier League statistics project that automatically processes football match results and generates a league table.

## Current Version: v0.3

### Features

- 20-team Premier League database.
- Match results stored using Python dictionaries.
- Automatic calculation of:
  - Games played
  - Wins, draws and losses
  - Goals scored and conceded
  - Goal difference
  - League points
- Automatic league table sorting based on:
  1. Matches played
  2. Points
  3. Goal difference
  4. Goals scored
- Formatted league table displayed in the terminal.

### Technologies Used

- Python
- Visual Studio Code
- Git and GitHub

### Project Structure

- `main.py` — Main program containing team data, match results, calculations and league table generation.
- `README.md` — Project documentation.
