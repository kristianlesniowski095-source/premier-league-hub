# Premier League Hub

A Python project that displays a Premier League league table using team statistics.

## Version
v0.2

## Current Features
- Stores team statistics using Python dictionaries.
- Automatically calculates goal difference.
- Sorts teams by points, goal difference and goals scored.
- Automatically assigns league positions.
- Displays a formatted league table.

## Technologies
- Python

## Current Status
Early development. More features will be added in future versions.
